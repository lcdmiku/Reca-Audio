# Qwen 联合音频与文本的编辑推理诊断

两组共用 Base、原始 Mel、编辑指令和逐样本 seed，使用 100 步 RF Euler 与 CFG=7。A1 把 16→4→16 kHz 的波形和指令送入同一次 Thinker 调用。四条接口样本的源波形与 Mel 投影哈希逐对一致。正式 A0 复用了逐点通过验证的历史生成。

A1 在本诊断集提高了编辑与保留的联合达标率。
编辑达标率同时下降。现有设置改善了背景保留，但会牺牲指令执行，当前证据不足以支持直接沿用该设置进入训练。
