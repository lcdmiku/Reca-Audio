# DiT block 恢复后的真实 T2A 生成对照

## 协议

本轮检验上一轮单步 velocity 的变化是否对应真实 T2A 生成的变化。代码版本 `63d5af0`，独立脚本 `runs/scripts/diagnose_dit_generation.py`，未改变训练、缓存或正常推理入口。独立只读代码审查未发现实质性问题；按用户要求只做语法、diff 检查和实际服务器运行，没有增加训练前测试矩阵。

- 四组：Base、10s Mix、Mix 恢复 Base block 12–23、Mix 恢复全部 Base block 0–35。恢复区间包含完整 block；每次干预前完整重载 Mix。只在内存交换权重，不保存新模型。
- 输入：直接读取 `runs/audits/dit_block_swap_v1/results.json` 的同一批 8 个唯一音频 SHA，每组第一条 caption。纯文本生成不读取对应音频作为条件。这批样本已参与前期干预探索，属于探索性诊断集，不是独立确认集。
- 配对：每个样本固定 seed=1235…1242，四组相同；100 步 rectified-flow Euler，CFG=6，生成头 float16。Qwen 和 VAE 使用原始 Base 权重。
- 长度：条件名义 10 秒，采样窗口显式设为 441000；VAE 下采样取整后实际输出 440320 帧、44100Hz，即 9.9845805 秒。所有组使用同一窗口。与此前默认 485100 点（11 秒）窗口 benchmark 的绝对分数不直接比较。
- 输出：复用 API 的后处理和 benchmark 的 PCM16 写入方式。每条音频生成后立即记录 prompt、SHA、seed、时长、路径与耗时。
- 评分：复用项目 `common.metrics` 的 LAION CLAP 模型和嵌入路径。逐音频计算 matched caption cosine，另以循环下一条 caption 作单一错配对照；每组评分前重置预处理 RNG。报告配对差值，不对 8 个音频计算 FAD。

远程目录：`/home/linchudeng/Reca-Audio/runs/audits/dit_generation_swap_v1/`。其中 `contract.json` 保存协议，`manifest.jsonl` 保存生成记录，四个子目录保存音频，`results.json` 保存逐样本评分与汇总。

## 解释

**本轮不支持把 block 恢复作为 T2A 改善方案。** 恢复中段和全部 block 相对 Mix 的均值均下降，仅各有 3/8 条提高。上一轮这两组文本 velocity 漂移由 12.61% 分别降到 8.55% 和 2.77%，却没有转化为更高的本轮 CLAP。因此不宜用“更接近 Base velocity”作为选择模型或冻结区间的直接准则。

单步诊断和真实生成还有两个明确的协议差异：前者在真实 target latent 加噪后的指定 t 上测量、CFG=1；本轮从纯噪声开始多步采样、CFG=6。各步误差及其交互也不同。本轮不能分离这些因素，更不能据此声称所有 velocity 诊断都无效。

Mix 在当前 8 条中有 6 条 CLAP 高于 Base，但该结论仅适用于此样本、seed 与长度协议，**不能推翻此前更大 AudioCaps benchmark 中 Mix 下降的结果**。例如第 01 条 Mix 比 Base 高 0.19540，第 06 条却低 0.22373，样本异质性明显。当前组别是根据同一批样本的前期响应结果选出的，且每个 prompt 只有一个 seed；不能作总体显著性或泛化结论。

四组 matched CLAP 均明显高于单一循环错配 caption 的均值，但 CLAP 只反映其嵌入度量下的文本音频匹配，不能替代人类对时序、音色和伪影的听评。本轮没有完成主观听评，也没有测试 audio-conditioned reconstruction 的保留情况。

## 下一步决策

1. 暂不采用恢复中段、恢复全部 block 或据此冻结层的长训练；当前没有收益证据。
2. 更有价值的确认是用不含本轮 8 个 SHA 的其余 held-out 音频组，先比较 Base/Mix，保持同一时长协议，并采用多个配对 seed，检查已有 T2A 下降是否受样本、seed 或长度协议影响。该确认仍是同一内部 split 上的研究验证，不应冒充全新外部 test。
3. 只有候选在独立样本上出现稳定 T2A 收益，再补 audio-conditioned reconstruction 与主观听评，验证研究目标中的两项能力是否同时保留。本轮到分析报告为止，没有追加训练或扩大评测。

本次改动仅新增独立生成诊断脚本及审计产物，无需重训或重建特征缓存。
