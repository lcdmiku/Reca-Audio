# 先 ReCA 后 T2A：配对评测完整指标

所有后训练组均为 7,070 条 AudioCaps、7,072 次曝光、峰值 LR 5e-6。主分析统计对 AudioCaps 及重建使用 81 个 SHA，对 MusicCaps 使用 89 个 SHA；“全量”、错排参考及分布/频谱指标均使用各域全部 89 条。CLAP 在生成任务衡量文本匹配，在重建任务衡量与参考音频的匹配。

区间为按 SHA 进行 10,000 次配对 bootstrap 的边际 95% 区间，未校正多重比较，不包含训练种子的波动。胜/平/负将绝对差不超过 1e-6 计作平。CLAP-FAD 和 PANNs FD/KL/IS 是分布指标，不是主观音质分数。CLAP-FAD 仅使用音频侧嵌入；重建 LSD 以 dB 计。
