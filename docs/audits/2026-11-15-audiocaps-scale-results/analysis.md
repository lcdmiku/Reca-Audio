# AudioCaps 扩容训练与配对评测

**同源 707 → 7,070 条音频的扩容，在 7,072 次曝光预算下未改善 AudioCaps T2A。** 大池的固定 held-out T2A loss 更接近 Base，但 CFG=1 的生成 CLAP 明显低于小池，CFG=6 的差值区间跨零。Pure 和 Mix 的主要收益仍体现在音频条件重建。

## 协议与完整性

四组从同一 Base 出发，各完成 7,072 次曝光、1,768 次更新，终点 checkpoint 均通过重载校验。三个大池组共享同一音频遍历和随机种子。Mix 有 3,536 次 ReCA 和 3,536 次 T2A 曝光。小池是大池的同源子集，训练预算一致，单条音频的重复次数随池大小而变。

评测于北京时间 2026-11-14 21:12 完成。共核对 1,780 条新生成记录及 445 条复用的 Base 记录，SHA、caption、seed、帧数与错配源均符合合同。AudioCaps 和重建各以 81 个未参与早期 8 条探索的 SHA 为主分析，MusicCaps 使用 89 个 SHA、T2M 模板。各组使用 100 步、441000 采样点窗口，实际输出 440320 帧。重建保持 4× 低通、静音 mel 条件和 CFG=1。

小池 T2A-only 在 CFG=1 比 Base 高 0.03732，95% CI [0.00295, 0.07208]。CFG=6 比 Base 低 0.03668，95% CI [−0.05813, −0.01476]。保持训练预算时，小池的每条样本重复更多。上述结果只支持这套预算和配置下的规模比较，无法判断增加训练轮数后大池能否反超。评测每条 prompt 使用一个 seed，训练每组只有一个 seed。

### ReCA、联合训练与跨域表现

- Pure 和 Mix 的匹配重建比同大池 T2A-only 分别高 0.10066 [0.07344, 0.12845] 和 0.05913 [0.03608, 0.08216]。把匹配减错配的优势与 Base 再做配对差值，Pure 为 +0.07680 [0.03381, 0.12089]，Mix 为 +0.05216 [0.01029, 0.09565]。两项证据均支持 ReCA 训练提高了对正确音频条件的利用。
- Pure 与 Mix 在 AudioCaps CFG=6 相对同大池 T2A-only 的差值分别为 +0.00598 [−0.02178, 0.03497] 和 −0.00115 [−0.02764, 0.02607]。当前没有建立 ReCA 对纯文本生成的净提升。四个训练组在 CFG=6 均低于 Base，各自配对区间低于零。
- Mix 的 MusicCaps CLAP 均值最高，相对 Base +0.02829 [0.00783, 0.04914]。两组 T2A-only 相对 Base 的区间也高于零。Mix 相对大池 T2A-only 为 +0.00575 [−0.00779, 0.02003]。本轮再次出现 AudioCaps 退化而 MusicCaps 改善的现象，但证据不足以把 MusicCaps 收益归因于 ReCA。
- 重建的指标不完全同步。Pure 的 paired CLAP 最高，CLAP-FAD 从 Base 的 0.78491 降至 0.61153，LSD 从 30.84833 降至 30.62644 dB。Mix 的 paired CLAP 与 CLAP-FAD 改善，LSD 为 30.91676 dB，略高于 Base。

大小池的终点 loss 排序与 CFG=1 的生成排序相反。固定加噪 latent 的单步 MSE 和从噪声开始的多步生成，需要作为不同证据解读。历史 2,000 曝光实验还改变了数据来源及训练预算，不能从新旧 checkpoint 的分差中隔离数据规模效应。此轮未单独检验学习率、优化器、梯度累积、4× 低通或微调层范围。
