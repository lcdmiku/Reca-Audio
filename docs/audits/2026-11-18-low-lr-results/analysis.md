# 低学习率后训练：T2A 配对生成结果

**在本轮 7,070 条训练音频、同一 seed 和 7,072 次曝光的配置下，峰值 LR 从 2e-5 降到 5e-6，明显缓解了 AudioCaps 文本生成退化，同时保留了 ReCA 的音频条件重建收益。尚无证据表明 ReCA 超过 Base 或优于同 LR 的 caption 监督。** MusicCaps 上出现了相反的取舍，不能把 5e-6 称为所有生成任务的最优学习率。

## 文本生成

表内为主分析集的配对 CLAP 均值（高 LR → 低 LR）。AudioCaps 使用 81 个未参与早期 8 条探索的 SHA；MusicCaps 使用 89 个 SHA 和 T2M 模板。AudioCaps CFG=6 为预定主要终点。

| 模型 | AudioCaps CFG=6 | AudioCaps CFG=1 | MusicCaps CFG=6 |
|---|---:|---:|---:|
| Base（复用） | 0.49570 | 0.29565 | 0.36946 |
| Pure ReCA | 0.45002 → 0.48584 | 0.23288 → 0.30677 | 0.39070 → 0.37236 |
| T2A-only | 0.44404 → 0.49365 | 0.24205 → 0.28981 | 0.39200 → 0.37021 |
| Mix 1:1 | 0.44289 → 0.49013 | 0.22944 → 0.30148 | 0.39775 → 0.37186 |

**降低 LR 的效应。** AudioCaps CFG=6 三组的低减高 LR 差值分别是 Pure +0.03582 [0.01767, 0.05489]、T2A-only +0.04961 [0.02567, 0.07552]、Mix +0.04724 [0.02419, 0.07086]。CFG=1 的三组增幅区间也均高于零。相同训练序列与评测噪声下，LR 制度是此前 AudioCaps 退化的一个可验证因素；比较没有单独改变优化器或梯度方差，不能据此判定梯度震荡、过拟合或 Adafactor 为退化机制。

**ReCA 能否替代或超过 caption 监督？** 在主要终点，低 LR 的 Pure 相对 Base 为 −0.00985 [−0.03038, +0.01042]；Pure 和 Mix 相对同 LR 的 T2A-only 分别为 −0.00781 [−0.02786, +0.01274] 和 −0.00352 [−0.02092, +0.01474]。低 LR 三组的均值都接近 Base，但未预设可接受的性能损失，不能用区间跨零宣称等效。Pure 没有使用逐条训练 caption，这里的“替代”只涉及后训练监督，Base 本身已有 T2A 能力。

**CFG 与域。** 在 CFG=1，Pure 均值高于 Base 0.01113 [−0.01808, +0.04243]，不足以宣称提升或改选主终点。MusicCaps 上三组低 LR 的均值都接近 Base；相对各自高 LR，T2A-only −0.02179 [−0.03894, −0.00486]、Mix −0.02589 [−0.04449, −0.00772]，Pure −0.01834 [−0.03817, +0.00091]。较小的参数更新改善 AudioCaps，同时削弱部分模型原有的跨域增益。无法据此定位是音乐内容、模板还是其他分布差异造成的。

## 音频分布与重建

AudioCaps CFG=6 下，降低 LR 后三组的 CLAP-FAD 和 PANNs FD 均降低。低 LR 下的 CLAP-FAD / FD 分别为 Base 0.3826 / 44.40、Pure 0.3984 / 45.22、T2A-only 0.3797 / 43.57、Mix 0.3865 / 46.71；KL 并未同步改善。MusicCaps 的低 LR T2A-only 和 Mix 的 FD 则分别由 40.63 升至 44.48、42.52 升至 44.08。这些是全量 89 条上的音频分布指标，未计算其置信区间，不能代替对自然度、失真或事件时序的盲听评分。

| 低 LR 模型 | 匹配重建 paired CLAP ↑ | 错配 CLAP | 匹配减错配 ↑ | 匹配 LSD (dB) ↓ |
|---|---:|---:|---:|---:|
| Base | 0.18804 | 0.03005 | 0.15799 | 30.85 |
| Pure ReCA | 0.34280 | 0.09729 | 0.24551 | 29.86 |
| T2A-only | 0.21992 | 0.04282 | 0.17711 | 30.39 |
| Mix 1:1 | 0.32520 | 0.08478 | 0.24042 | 29.93 |

Pure、Mix 的**匹配减错配**优势，再相对 T2A-only 做同 SHA 的配对差值，分别为 +0.06840 [0.03209, 0.10560]、+0.06331 [0.02963, 0.09859]。这排除了仅靠所有生成音频整体更像参考集来解释全部重建收益；仍无法区分模型利用了声学细节、事件语义，还是两者兼有。纯文本条件下没有观察到同样确定的优势。

## 最有价值的下一组对照

若继续训练，优先固定 5e-6，增加一个 **与 Mix 使用完全相同 caption 的 T2A 对照**：每次更新只保留原 Mix 两个文本槽，沿用文本样本、种子和每条 loss 的 1/4 权重；另两个音频槽不贡献梯度。保留 1,768 次计划更新和原 LR 曲线。这检验的是“固定标注预算，增加 ReCA 项是否让文本生成更好”，与现有“总曝光相同但 caption 剂量不同”的对照互补。不同时改滤波、优化器或 DiT 层。若要宣称可以替代 caption，先定义可接受的 T2A 损失，再用独立确认集、另一训练 seed 和分别评质量/文本遵循度的盲听复核。
