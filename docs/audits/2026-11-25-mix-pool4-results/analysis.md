# 四 token 池化对文本生成和音频重建的影响

**四 token 池化未在预定的 AudioCaps 主终点显示 T2A 收益。** Pool4 与原 Mix 的配对 CLAP 差值为 −0.00018，在 81 条音频中 41 胜、40 负。相对相同 caption 预算的仅文本槽组，差值为 −0.00526。MusicCaps 上相对原 Mix 出现正向差异，音频条件重建对正确输入的依赖则减弱。当前证据支持保留原 Mix 作为重建基线。

## 文本生成

## 音频分布与重建

AudioCaps CFG=6 的质量代理指标方向不一致。原 Mix → 池化 Mix 的 CLAP-FAD 为 0.38648 → 0.39353，FD 为 46.71273 → 46.35092，KL 为 2.23950 → 2.25705，IS 为 7.84759 → 7.99722。MusicCaps 的 CLAP-FAD（0.64600 → 0.62801）、FD（44.08220 → 42.97466）和 KL（1.33586 → 1.31815）均降低，IS 略降（3.21138 → 3.17714）。分布指标使用全部 89 条，未估计区间。池化组缺少直接盲听，自然度或失真改善仍待验证。

| 音频条件 CLAP（81 SHA） | 仅文本槽 | 原 Mix | 池化 Mix | 池化 − 原 Mix [95% CI] |
|---|---:|---:|---:|---|
| 正确输入 | 0.21399 | 0.32520 | 0.28416 | −0.04104 [−0.06211, −0.02127] |
| 错配输入 | 0.03793 | 0.08478 | 0.08786 | +0.00307 [−0.00958, +0.01591] |
| 正确减错配 | 0.17606 | 0.24042 | 0.19630 | −0.04412 [−0.06769, −0.02189] |

池化组正确条件的 CLAP 仍高于仅文本槽 0.07017 [0.03473, 0.10507]；扣除错配得分后，额外匹配优势为 +0.02024 [−0.01900, +0.06005]。相对原 Mix，正确条件下 CLAP-FAD 从 0.57312 升至 0.60463，而 LSD 从 29.92900 降至 29.46224 dB。频谱距离与嵌入相似度反映了不同变化。

这次同时改变了新模型训练和重建推理时的音频条件。匹配优势下降支持局部 token 变化有助于原配方重建，但仍无法区分权重学到了什么、推理时即时丢失了什么，也无法把差异唯一归因于音色或事件语义。文本评测使用相同的纯文本通路。
