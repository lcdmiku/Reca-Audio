# 固定 caption 预算的配对评测指标

预定主比较为 AudioCaps CFG=6 的 Mix 1:1 减仅文本槽。两组各有 3,536 次有效文本曝光并使用完全相同的文本记录；T2A-only（全量文本）有 7,072 次文本曝光。Base 为原始 Audio-Omni。

各表的均值、中位数和标准差取自主要分析集。AudioCaps 与音频重建各有 81 个 SHA，预先排除了 8 个探索样本；MusicCaps 有 89 个 SHA。全量均值、移位评分和音频分布／频谱指标使用全部 89 个 SHA。标准差使用总体标准差。对每个设置，胜、平、负均从表中列出的参照组方向计算，绝对差不超过 1e-6 计平。区间来自按 SHA 的 10,000 次配对 bootstrap，表示该评测样本的边际 95% 区间，未作多重比较校正，训练种子取 42。

文本生成的 CLAP 比较生成音频与 caption，重建的 CLAP 比较生成音频与目标音频。“移位”将评分参考循环移动一位后重新计算均值。错配重建本身也将条件音频循环移动一位，因此该设置的移位评分反映生成音频与实际输入音频的相似度。

CLAP-FAD 和 PANNs FD 衡量生成与参考音频在嵌入空间的分布距离。PANNs KL 和 IS 概括事件分类器的输出；LSD 衡量重建与目标音频的对数谱距离（dB）。表内箭头给出常用指标方向。对这些全量统计仅作描述，本轮没有两组直接盲听评分。破折号表示该设置未计算相应指标。
